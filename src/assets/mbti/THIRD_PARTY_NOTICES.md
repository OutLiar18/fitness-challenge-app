# MBTI Legacy Profile Emblem Sources

Their source silhouettes come from Game-icons.net and are used under Creative Commons Attribution 3.0.

Modifications by Champions Legacy Challenge:
- recolouring;
- custom gradient palette;
- custom shield/crest framing;
- scaling and compositing;
- decorative accent geometry.

These assets deliberately contain no MBTI letter text. The four-letter type remains application metadata/copy,
while the emblem represents the Champions Legacy mythic identity.
