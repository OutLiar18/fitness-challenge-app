v0.26 Checkpoint 26F hardens the trusted account-deletion processor against interruption between Firestore batches. Before a new execution is marked processing, the operator tool now writes a private local recovery plan that freezes the execution ID, original audit fingerprint, source/anonymised identities, exact document paths and modes, league participant-count decrements and planned counts. The plan SHA-256 is bound into the trusted execution record. Processing records phase and batch progress. A processing/failed execution may resume only when the original recovery plan is available and matches the execution/request contract; missing, drifted or conflicting recovery state fails closed. Replayed deletes are idempotent and documents already anonymised by the same execution are skipped. No account deletion was executed and no Firebase deployment occurred in 26F.
