# Champions Legacy Challenge — Design Language

Version: 2.1
Last updated: 1 August 2026

## Identity

Champions Legacy Challenge should feel modern, premium, calm, motivating and slightly adventurous.

## v0.7 application shell

- Desktop: collapsible left sidebar.
- Tablet/mobile: top header, slide-out drawer and bottom primary navigation.
- Active navigation uses shape, colour and position—not colour alone.
- The Log action receives stronger emphasis because it is the core task.
- Future modules are labelled as previews.

## Surfaces

- Cards group one primary purpose.
- Primary gradients are reserved for high-value actions and identity moments.
- Soft surfaces support secondary information.
- Shadows communicate hierarchy rather than decoration.

## Motion

Motion should explain interaction:

- navigation expansion;
- active state changes;
- progress fills;
- temporary notifications.

Reduced-motion preferences must be respected.

## Responsive behaviour

- No important feature may exist only in desktop navigation.
- Bottom navigation contains the five most frequent destinations.
- Mobile touch targets should be at least approximately 42–44 px.
- Content remains readable from 320 px upward.

## Playful details

Small trophy interactions, rotating motivation and future-page humour may add personality. They remain secondary to clarity and accessibility.

# v0.15 Navigation and Analytics Addendum

- Desktop navigation groups related destinations instead of presenting one undifferentiated list.
- The player identity panel is the desktop Profile entry point; duplicate Profile links are avoided.
- Inbox uses clear tabs and labels so colour is never the only distinction between public and private messages.
- Analytics favours readable summaries, accessible labels and modest charts over dashboard clutter.
- C.H.A.O.S. prerequisites use text, symbols and completion wording rather than colour alone.
