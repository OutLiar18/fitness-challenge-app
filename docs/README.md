- `01_CURRENT_DEVELOPMENT/` — only actively relevant development state.
- `02_GAME_DESIGN/` — authoritative game/product rules.
- `03_ARCHITECTURE/` — architecture, data model and ADRs.
- `04_DEVELOPMENT/` — engineering and operational guidance.
- `05_DESIGN/` — UI, accessibility and responsive design rules.
- `06_CHAT_HANDOVER/` — concise continuity material.
- `07_HISTORY/` — changelog, version history and release evidence.

Completed version-specific audits and checkpoint notes should not accumulate in `01_CURRENT_DEVELOPMENT`; Git history and `07_HISTORY/` are the historical record.
