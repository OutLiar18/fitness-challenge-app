## Version format

Champions Legacy Challenge uses semantic versioning: `MAJOR.MINOR.PATCH`.

- **Major** — breaking architectural or product milestone.
- **Minor** — backwards-compatible feature phase.
- **Patch** — focused fix or small refinement.

## Pre-v1.0 rule

All `0.x.x` releases remain active development. Version 1.0.0 requires explicit user approval after full functional, visual, responsive, accessibility, security and operational review. Do not create a v1.0 tag early.

## Release record rule

Every release updates the Changelog, Release Notes and this table. Candidate-to-deployed status is finalised by the release script included in the main updater; no separate documentation archive is used.
